## Orchestrate your pentest

Hexestra is an AI-native penetration-testing IDE where the operator and AI Agent work
on the same operational surface. They share the browser, terminals, traffic, shells,
asset graph, tasks, evidence, and project state.

You can let the Agent execute autonomously within the engagement's Scope, guide or
approve consequential actions, and take over the same tools at any time.

## Keep your tools

- Claude Code remains the Agent runtime, with its normal authentication, models,
  settings, Skills, and MCP configuration.
- Burp Suite remains the operator's traffic workbench through the authenticated
  Hexestra Bridge.
- PowerShell, WSL, SSH, and raw sessions remain real shells shared by operator and
  Agent.

Hexestra adds orchestration and shared state around the existing toolchain.

## Included in this preview

- integrated project browser, terminals, Traffic workbench, Shell Manager, and NetMap;
- task, Scope, evidence, finding, vulnerability, and report workflows;
- controlled Claude Code modes with visible permissions and activity;
- native Claude Code execution on Windows, Linux, and macOS;
- project persistence and non-destructive conversation branching;
- optional user-installed mitmproxy capture and Burp Suite mirroring.

## Availability

- **Supported source-run preview:** Windows x64, Linux x64, macOS Intel, and macOS Apple Silicon
- **Optional:** WSL on Windows, Burp Suite, and a user-installed mitmproxy 12.2.3
- **Release asset:** reviewed source archive
- **Installers:** not included in this preview

This preview may include breaking changes before v1.0. Users install Claude Code and
mitmproxy separately; Hexestra discovers the configured executables without downloading
or updating them.

## Security and responsible use

Use Hexestra only on systems you own or are explicitly authorized to test. Keep Scope
accurate, obtain approval for destructive or privacy-impacting actions, and treat
exported evidence as sensitive.
