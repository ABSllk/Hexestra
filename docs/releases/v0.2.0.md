# Hexestra v0.2.0

Hexestra 0.2.0 improves the shared operating surface between security operators and
the Claude Agent. This release focuses on theme-aware branding, native Subagent
visibility, browser-assisted workflows, asset operations, and release reliability.

## Highlights

### System-aware appearance and Hexestra branding

- Choose System, Dark, or Light under **Settings > General > Interface**.
- Theme changes apply immediately across Electron surfaces, terminal sessions,
  Monaco editors, NetMap, dialogs, scrollbars, forms, and status areas.
- Existing terminal and editor sessions retain their content while appearance changes.
- The welcome screen, title bar, desktop package, and README now use the Hexestra
  wordmark and standalone application mark.

### Native Subagent visibility

- Claude Subagent lifecycle events are projected into the conversation timeline in
  real time.
- Subagent lineage, status, permission provenance, activity, and results persist with
  project state.
- A dedicated detail view makes concurrent delegated work inspectable without losing
  the parent conversation context.

### Browser and asset workflows

- The Agent can use the integrated browser automation runtime through explicit tool
  contracts and policy checks.
- Asset inventory actions provide direct NetMap, browser, copy, and scoped Agent
  rescan operations.
- NetMap, asset details, status information, and chat controls received focused visual
  and interaction refinements.

### Zero-install Traffic Capture

- Packaged builds include an official platform-specific mitmdump runtime;
  no separate mitmproxy installation or PATH configuration is required.
- Runtime archives are downloaded from mitmproxy's official distribution host during
  packaging and verified against pinned SHA-256 digests from its Sigstore provenance.
- A manually selected executable remains available as an expert override. Hexestra
  continues to generate and pin a project-specific CA without silently changing the
  operating-system trust store.

## Reliability and distribution

- CI now validates and packages the desktop application on Windows x64, Linux x64,
  macOS Intel, and macOS Apple Silicon runners.
- CI downloads contain final `.exe`, `.AppImage`, or `.dmg` distributables instead of
  unpacked application directories.
- Platform-specific `node-pty` prebuild validation fails early when a compatible native
  package is unavailable.
- Public-source auditing rejects local workflow state, credentials, captures, copied
  runtimes, generated Python caches, and unknown top-level entries.
- Electron, `@xterm/addon-fit`, and `tailwind-merge` were updated.

## Compatibility

- Existing application settings migrate to the new theme-aware schema and default to
  following the operating-system appearance.
- Existing Hexestra projects and legacy migration identifiers remain supported.
- Claude Code remains user-installed. Packaged builds bundle the audited mitmdump
  runtime but no authentication data, shared CA private key, or other third-party
  runtime.

## Upgrade

Pull the `v0.2.0` source, install the locked Node.js 24 dependencies, and start the
desktop application:

```bash
npm ci
npm run electron:dev
```

Run the release quality gates before packaging:

```bash
npm run audit:public
npm run check
```

### macOS first launch for this unsigned release

This release is not code-signed or notarized. After copying `Hexestra.app` to
`/Applications`, use **System Settings > Privacy & Security > Open Anyway** if macOS
blocks the first launch and you trust the downloaded file. As a Terminal alternative,
run:

```bash
xattr -dr com.apple.quarantine "/Applications/Hexestra.app"
```

Use Hexestra only on systems you own or are explicitly authorized to assess.

## 中文说明

Hexestra 0.2.0 改进了安全操作员与 Claude Agent 之间的共享工作界面。本版本重点
更新了双主题品牌、原生 Subagent 可见性、浏览器辅助工作流、资产操作和发布可靠性。

### 主要更新

#### 跟随系统的外观与 Hexestra 品牌

- 可在 **设置 → 常规 → 界面** 中选择“系统”“深色”或“浅色”。
- 主题会立即同步到 Electron 界面、终端、Monaco 编辑器、NetMap、弹窗、滚动条、表单
  和状态区域。
- 切换外观时，已有终端和编辑器会话会保留内容。
- 欢迎页、标题栏、桌面应用图标和 README 现在使用 Hexestra 完整字标及独立应用图标。

#### 原生 Subagent 可见性

- Claude Subagent 生命周期事件会实时显示在对话时间线中。
- Subagent 的血缘关系、状态、权限来源、活动和结果会随项目状态持久化。
- 独立详情页可以查看并行委派工作，同时保留父级对话上下文。

#### 浏览器与资产工作流

- Agent 可以通过明确的工具契约和策略检查使用集成浏览器自动化运行时。
- 资产清单操作支持直接在 NetMap 中查看、打开浏览器目标、复制地址或 JSON，以及请求
  有范围限制的 Agent 重新扫描。
- NetMap、资产详情、状态信息和聊天控制经过了针对性的视觉与交互优化。

#### 零安装流量捕获

- 打包版内置官方的平台对应 mitmdump 运行时，无需单独安装 mitmproxy 或配置
  PATH。
- 打包时从 mitmproxy 官方分发地址下载运行时，并使用其 Sigstore 来源证明中的固定
  SHA-256 摘要进行校验。
- 仍可手动选择可执行文件作为专家覆盖选项。Hexestra 会继续生成并固定项目专属 CA，
  不会静默修改操作系统信任库。

### 可靠性与分发

- CI 现在会在 Windows x64、Linux x64、macOS Intel 和 macOS Apple Silicon runner 上
  验证并打包桌面应用。
- CI 下载内容只包含最终的 `.exe`、`.AppImage` 或 `.dmg` 分发文件，不再包含未打包的
  应用目录。
- 平台专用 `node-pty` 预编译包验证会在缺少兼容原生包时尽早失败。
- 公共源码审计会拒绝本地工作流状态、凭据、抓包文件、复制的运行时、生成的 Python
  缓存和未知顶层条目。
- Electron、`@xterm/addon-fit` 和 `tailwind-merge` 已升级。

### 兼容性

- 现有应用设置会迁移到新的主题配置，并默认跟随操作系统外观。
- 现有 Hexestra 项目和旧版迁移标识继续受支持。
- Claude Code 仍需用户自行安装。打包版包含经过审计的 mitmdump 运行时，但不包含认证
  数据、共享 CA 私钥或其他第三方运行时。
